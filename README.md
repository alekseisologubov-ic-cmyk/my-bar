# My Bar POS

Phase 1 MVP for a bar operations system.

## Current features

- POS menu
- Add items to cart
- Cash, card, and mobile payment recording
- Tips
- Discounts
- Daily sales dashboard
- Sales by category
- Recent orders
- Void order
- Daily closing
- Browser local storage

## Phase 2

- Supabase/PostgreSQL database
- Login
- Staff roles
- Inventory
- Tables and bar tabs
- Refunds
- Real reports
- Vercel production environment
